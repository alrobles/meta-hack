## 4. The finding that costs the most: the agent decides nothing

```
data/decisions_all.jsonl   560 decisions → 560 "accept", 560 switch_to="none", 559 "high"
data/fit_catalog.csv       101,376 rows → 101,376 flag "accepted_global"
data/species_winner.csv    1,148 species → every one with 88/88 pairs accepted
```

The "typed decision layer" (the T1 design in `docs/plan.md`) only ever sees inputs that
already passed the deterministic gate, so its output distribution is degenerate. muse-wonder
says so out loud in the briefing it generated:

> "No species were flagged. 589 Tier-1 accepts were recorded…"

This is the single highest-value thing to fix, because it hits two scoring surfaces at once:
`Use of Meta AI Tooling (25%)` — "did they go beyond a basic integration" — and the **$5,000
Best Agentic Use-Case** bonus ("level of autonomy, effectiveness in making decisions").

**The hard cases already exist in the data** (top-5 AIC spread per species):

```
Geotrygon chrysia 3.44 · Callorhinus ursinus 3.72 · Balaenoptera borealis 3.76
Urocyon littoralis 4.43 · Pterodroma arminjoniana 4.79 · Arctocephalus philippii 4.91
```

**Required change (acceptance criteria):**

1. Route **only the ambiguous tail** to the agent: `top5_aic_spread < 15`, `n < 100`,
   `marine-ish flagged`, `n_eco_m` outliers, and any species whose winner is not
   `accepted_global`.
2. Make the veredict **change the output**: `drop` removes the species from the served
   catalog; `switch_to` triggers a real refit (skew_t / ip_weighted) whose new AIC replaces
   the old one; `flag_review` sets a visible flag consumed by the app.
3. Emit `decisions.jsonl` with `changed: true/false` and write a **delta table**
   (`species · decision · why · old AIC → new AIC · in_map before/after`) to
   `data/serve/decisions_delta.csv`.
4. Non-negotiable: the delta must be non-trivial (not 100% accept). A run where the agent
   changes nothing is a failed run — treat it as a bug, not a result.

## 7. Guardrails for whoever works here

- **Do not** use `*-contributor` models for anything that is not public. The repo becomes
  public, so repo content is fine; anything from the lab is not.
- **Do not** commit `data/` (gitignored by design) or any key.
- **Do not** run compute-heavy work on cluster login nodes; everything beyond `squeue`/`sbatch`
  goes through the scheduler (rule already in `docs/plan.md`).
- Keep `MODEL_API_KEY` in the environment only; never in code.
- Cost discipline: every Meta call is metered. Log spend via `MetaClient.spend`, and keep bulk
  extraction on the contributor tier.
